# 宠物商店管理系统

一个基于Java的宠物商店管理系统，采用MVC架构设计，支持控制台和GUI两种界面。

## 功能特性

### 宠物管理
- 添加、删除、修改、查询宠物信息
- 按种类和状态筛选宠物
- 支持狗、猫等多种宠物类型

### 库存管理
- 查询库存信息
- 更新库存数量
- 设置库存预警阈值
- 库存统计功能

### 销售管理
- 添加销售记录
- 查询销售记录
- 按时间范围筛选销售记录

### 数据统计
- 库存统计柱状图
- 销售趋势折线图
- 支持导出为PNG图片和PDF文件

## 技术架构

### MVC分层架构

```
┌─────────────────────────────────────┐
│          视图层 (View/GUI)          │
├─────────────────────────────────────┤
│         控制器层 (Controller)        │
├─────────────────────────────────────┤
│         业务逻辑层 (Service)         │
├─────────────────────────────────────┤
│         数据访问层 (DAO)             │
├─────────────────────────────────────┤
│         数据模型层 (Model)           │
└─────────────────────────────────────┘
```

## 运行要求

- Java 8 或更高版本
- JFreeChart 库（用于数据统计图表）
- iText 库（用于PDF导出）

## 使用说明

### 控制台模式

运行 `Main.java` 启动控制台版本：

```bash
javac -cp .:lib/* src/com/petshop/Main.java
java -cp .:lib/* com.petshop.Main
```

### GUI模式

系统提供基于Swing的图形界面，包含以下功能模块：
- 登录对话框
- 主窗口框架（顶部通栏 + 侧边栏导航 + 内容区域）
- 宠物管理面板
- 库存管理面板
- 销售管理面板
- 数据统计面板（支持图表展示和导出）

## 数据存储

系统使用Java对象序列化将数据保存到本地文件：
- `data/pets.dat` - 宠物数据
- `data/inventory.dat` - 库存数据
- `data/sales.dat` - 销售记录

## 依赖库

| 库名称 | 版本 | 用途 |

| iText | 2.1.7 | PDF导出 |

## 开发说明

### 添加新的宠物类型

1. 在 `model` 包中创建新的宠物类，继承 `Pet` 类
2. 实现必要的方法和序列化接口
3. 在 `PetDao` 中添加相应的数据访问方法

### 添加新的功能模块

1. 在 `view` 或 `gui` 包中创建视图类
2. 在 `controller` 包中创建控制器类
3. 在 `service` 包中创建业务逻辑类
4. 在 `MainController` 或 `MainFrame` 中注册新模块
