# 宠物商店管理系统 - 课程设计说明书

## 一、项目选题说明

### 1.1 项目背景

随着人们生活水平的提高，宠物已经成为许多家庭的重要成员。宠物商店作为宠物交易和服务的场所，需要高效地管理宠物信息、库存和销售记录。传统的手工管理方式效率低下，容易出错，因此开发一个宠物商店管理系统具有重要的实际意义。

本项目是面向对象程序设计课程的期末项目，旨在通过开发一个完整的宠物商店管理系统，综合运用课程所学的Java编程知识和面向对象设计思想，检验学生的软件开发能力。

### 1.2 项目意义

1. **实践面向对象编程**：通过设计类层次结构、使用继承和接口，深入理解面向对象编程的核心概念
2. **掌握MVC架构**：采用Model-View-Controller分层架构，提高代码的可维护性和可扩展性
3. **应用IO流技术**：使用Java对象序列化实现数据的本地持久化存储
4. **培养软件工程素养**：遵循良好的编码规范，编写清晰的中文注释

### 1.3 项目目标

- 实现宠物信息的增删改查（CRUD）操作
- 实现库存管理和销售记录管理
- 提供友好的控制台交互界面
- 所有数据通过IO流保存在本地文件中
- 应用面向对象设计思想，采用MVC分层架构

## 二、需求分析

### 2.1 功能需求

#### 2.1.1 宠物信息管理
- **添加宠物**：输入宠物ID、名称、种类、年龄、价格、状态等信息
- **删除宠物**：根据宠物ID删除宠物信息
- **修改宠物**：根据宠物ID修改宠物信息
- **查询宠物**：根据宠物ID查询宠物详细信息
- **列出所有宠物**：以表格形式显示所有宠物信息
- **按种类筛选**：根据宠物种类筛选宠物列表
- **按状态筛选**：根据宠物状态筛选宠物列表

#### 2.1.2 库存管理
- **查询库存**：显示所有宠物的库存信息
- **更新库存**：增加或减少指定宠物的库存数量
- **设置库存预警**：设置库存预警阈值
- **检查库存预警**：显示库存低于预警阈值的宠物
- **库存统计**：显示库存总数量和总价值

#### 2.1.3 销售管理
- **添加销售记录**：记录宠物销售信息，自动减少库存
- **查询销售记录**：根据记录ID查询销售详情
- **列出所有销售记录**：以表格形式显示所有销售记录
- **按时间范围查询**：根据时间范围筛选销售记录

#### 2.1.4 数据统计
- **库存统计**：显示库存总数量、总价值等信息
- **销售统计**：显示总销售额、总销售数量等信息

### 2.2 非功能需求

1. **数据持久化**：所有数据通过IO流保存在本地文件中，程序重启后数据不丢失
2. **异常处理**：实现完善的异常处理机制，保证程序稳定运行
3. **用户界面**：提供友好的控制台交互界面，包括格式化输出表格和清晰的导航菜单
4. **代码规范**：遵循Java编码规范，包含规范的中文注释

### 4.2 数据访问层

#### 4.2.1 FileDao类（文件操作工具类）

```java
package com.petshop.dao;

import java.io.*;

public class FileDao {
    
    // 保存对象到文件（序列化）
    public static void saveObject(String filePath, Object obj) throws IOException {
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(filePath))) {
            oos.writeObject(obj);
        }
    }
    
    // 从文件读取对象（反序列化）
    public static Object loadObject(String filePath) throws IOException, ClassNotFoundException {
        File file = new File(filePath);
        if (!file.exists()) {
            return null;
        }
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream(filePath))) {
            return ois.readObject();
        }
    }
    
    // 保存文本到文件
    public static void saveText(String filePath, String content) throws IOException {
        try (BufferedWriter writer = new BufferedWriter(new FileWriter(filePath))) {
            writer.write(content);
        }
    }
    
    // 从文件读取文本
    public static String loadText(String filePath) throws IOException {
        File file = new File(filePath);
        if (!file.exists()) {
            return "";
        }
        StringBuilder sb = new StringBuilder();
        try (BufferedReader reader = new BufferedReader(new FileReader(filePath))) {
            String line;
            while ((line = reader.readLine()) != null) {
                sb.append(line).append("\n");
            }
        }
        return sb.toString();
    }
    
    // 备份文件
    public static void backupFile(String sourcePath, String backupPath) throws IOException {
        File source = new File(sourcePath);
        if (!source.exists()) {
            return;
        }
        File backupDir = new File(backupPath).getParentFile();
        if (!backupDir.exists()) {
            backupDir.mkdirs();
        }
        try (InputStream in = new FileInputStream(source);
             OutputStream out = new FileOutputStream(backupPath)) {
            byte[] buffer = new byte[1024];
            int length;
            while ((length = in.read(buffer)) > 0) {
                out.write(buffer, 0, length);
            }
        }
    }
}
```

**设计说明**：
- 提供静态方法，方便调用
- 使用try-with-resources语句，确保资源自动关闭
- 支持对象序列化和文本文件读写
- 提供文件备份功能

### 4.3 业务逻辑层

#### 4.3.1 PetService类（宠物业务逻辑类）

```java
package com.petshop.service;

import com.petshop.dao.InventoryDao;
import com.petshop.dao.PetDao;
import com.petshop.exception.BusinessException;
import com.petshop.model.Inventory;
import com.petshop.model.Pet;
import java.util.List;

public class PetService {
    private PetDao petDao;
    private InventoryDao inventoryDao;
    
    public PetService() {
        this.petDao = new PetDao();
        this.inventoryDao = new InventoryDao();
    }
    
    public PetService(PetDao petDao, InventoryDao inventoryDao) {
        this.petDao = petDao;
        this.inventoryDao = inventoryDao;
    }
    
    // 添加宠物
    public Pet addPet(String id, String name, String species, int age, double price, String status) 
            throws BusinessException {
        if (id == null || id.trim().isEmpty()) {
            throw new BusinessException("宠物ID不能为空");
        }
        if (name == null || name.trim().isEmpty()) {
            throw new BusinessException("宠物名称不能为空");
        }
        if (age < 0) {
            throw new BusinessException("年龄不能为负数");
        }
        if (price < 0) {
            throw new BusinessException("价格不能为负数");
        }
        
        Pet pet = new Pet(id, name, species, age, price, status);
        if (!petDao.add(pet)) {
            throw new BusinessException("宠物ID已存在");
        }
        // 自动创建库存记录，默认库存10，预警阈值5
        inventoryDao.save(new Inventory(id, 10, 5));
        return pet;
    }
    
    // 删除宠物
    public void deletePet(String id) throws BusinessException {
        if (petDao.findById(id) == null) {
            throw new BusinessException("宠物不存在");
        }
        petDao.delete(id);
    }
    
    // 修改宠物
    public Pet updatePet(String id, String name, String species, int age, double price, String status) 
            throws BusinessException {
        Pet pet = petDao.findById(id);
        if (pet == null) {
            throw new BusinessException("宠物不存在");
        }
        
        if (name != null && !name.trim().isEmpty()) {
            pet.setName(name);
        }
        if (species != null && !species.trim().isEmpty()) {
            pet.setSpecies(species);
        }
        if (age >= 0) {
            pet.setAge(age);
        }
        if (price >= 0) {
            pet.setPrice(price);
        }
        if (status != null && !status.trim().isEmpty()) {
            pet.setStatus(status);
        }
        
        petDao.update(pet);
        return pet;
    }
    
    // 查询宠物
    public Pet getPet(String id) throws BusinessException {
        Pet pet = petDao.findById(id);
        if (pet == null) {
            throw new BusinessException("宠物不存在");
        }
        return pet;
    }
    
    // 获取所有宠物
    public List<Pet> getAllPets() {
        return petDao.findAll();
    }
    
    // 按种类筛选
    public List<Pet> getPetsBySpecies(String species) {
        return petDao.findBySpecies(species);
    }
    
    // 按状态筛选
    public List<Pet> getPetsByStatus(String status) {
        return petDao.findByStatus(status);
    }
}

package com.petshop.controller;

import com.petshop.dao.InventoryDao;
import com.petshop.dao.PetDao;
import com.petshop.dao.SalesRecordDao;
import com.petshop.service.InventoryService;
import com.petshop.service.PetService;
import com.petshop.service.SalesService;
import com.petshop.view.*;

import java.util.Scanner;

public class MainController {
    private MainMenuView mainMenuView;
    private PetController petController;
    private InventoryController inventoryController;
    private SalesController salesController;
    private StatisticsView statisticsView;
    
    public MainController() {
        Scanner scanner = new Scanner(System.in);
        
        // 创建共享的DAO实例
        PetDao petDao = new PetDao();
        InventoryDao inventoryDao = new InventoryDao();
        SalesRecordDao salesRecordDao = new SalesRecordDao();
        
        // 创建共享的Service实例
        PetService petService = new PetService(petDao, inventoryDao);
        InventoryService inventoryService = new InventoryService(petDao, inventoryDao);
        SalesService salesService = new SalesService(petDao, inventoryDao, salesRecordDao);
        
        this.mainMenuView = new MainMenuView(scanner);
        this.petController = new PetController(new PetManagementView(scanner), petService);
        this.inventoryController = new InventoryController(new InventoryManagementView(scanner), inventoryService);
        this.salesController = new SalesController(new SalesManagementView(scanner), salesService);
        this.statisticsView = new StatisticsView(scanner);
    }
    
    // 运行系统
    public void run() {
        mainMenuView.showMessage("欢迎使用宠物商店管理系统！");
        
        boolean running = true;
        while (running) {
            int choice = mainMenuView.showMenu();
            switch (choice) {
                case 1: petController.run(); break;
                case 2: inventoryController.run(); break;
                case 3: salesController.run(); break;
                case 4: showStatistics(); break;
                case 0:
                    if (mainMenuView.confirmExit()) {
                        running = false;
                        mainMenuView.showMessage("感谢使用，再见！");
                    }
                    break;
                default: mainMenuView.showMessage("无效的选择，请重新输入");
            }
        }
    }
    
    private void showStatistics() {
        boolean running = true;
        while (running) {
            int choice = statisticsView.showMenu();
            switch (choice) {
                case 1: 
                    inventoryController.run();
                    break;
                case 2:
                    salesController.run();
                    break;
                case 0: running = false; break;
                default: statisticsView.showMessage("无效的选择");
            }
        }
    }
}
```

## 六、总结体会

### 6.1 项目收获

通过本次宠物商店管理系统的开发，我获得了以下收获：

1. **深入理解面向对象编程**：通过设计类层次结构、使用继承和接口，真正理解了面向对象编程的核心思想。Pet类作为基类，Dog和Cat类作为子类，体现了继承的特性。

2. **掌握MVC架构**：采用Model-View-Controller分层架构，将数据模型、业务逻辑和用户界面分离，提高了代码的可维护性和可扩展性。

3. **应用IO流技术**：使用Java对象序列化实现数据的本地持久化存储，掌握了File类和IO流技术。

4. **异常处理实践**：通过自定义BusinessException类，实现了完善的异常处理机制，保证了程序的稳定运行。

5. **软件工程素养**：遵循良好的编码规范，编写清晰的中文注释，提高了代码的可读性和可维护性。

### 6.2 遇到的问题及解决方法

1. **数据共享问题**：最初每个Service各自创建DAO实例，导致数据不一致。通过依赖注入，共享DAO实例解决了这个问题。

2. **序列化问题**：在实现对象序列化时，需要确保所有数据模型类都实现Serializable接口，并定义serialVersionUID。

3. **用户输入处理**：在处理用户输入时，需要考虑异常情况，如输入非数字字符等，通过try-catch语句处理。

### 6.3 不足之处

1. **界面相对简单**：由于时间限制，系统仅提供控制台界面，用户体验有限。

2. **功能相对基础**：系统实现了基本的CRUD操作，但缺乏高级功能，如数据导出、报表生成等。

3. **测试不够充分**：虽然进行了基本的功能测试，但缺乏系统的单元测试和集成测试。

### 6.4 改进方向

1. **增加图形界面**：可以考虑使用JavaFX或Swing开发图形用户界面，提高用户体验。

2. **使用数据库存储**：将数据存储从文件IO改为数据库，提高数据管理的效率和安全性。

3. **增加高级功能**：如数据导出、报表生成、用户权限管理等。

4. **完善测试**：编写系统的单元测试和集成测试，确保代码质量。

### 6.5 总结

本次课程设计让我将课堂上学到的面向对象编程知识应用到实际项目中，加深了对Java编程语言和面向对象设计思想的理解。通过开发宠物商店管理系统，我不仅掌握了MVC架构、IO流技术、异常处理等核心知识，还培养了软件工程素养和解决问题的能力。虽然系统还存在一些不足，但这次经历为我今后的软件开发打下了坚实的基础。
